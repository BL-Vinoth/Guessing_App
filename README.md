NUMBER GUESSING GAME (JAVA)

A simple Java console-based guessing game where the player tries to guess a randomly generated number within a limited number of attempts.

FEATURES

Random number generation

User input using Scanner

Feedback for each guess (Too High / Too Low)

Limited number of attempts

Win and lose conditions

Easy to understand for beginners

TECHNOLOGIES USED

Programming Language: Java

Java Version: Java 8 or higher

Platform: Console application

HOW TO RUN THE PROGRAM

Compile the program:
javac GuessingApp.java

Run the program:
java GuessingApp

HOW TO PLAY

The program generates a random number (e.g., between 1 and 100).

Enter your guess when prompted.

The program will tell you if your guess is too high or too low.

Keep guessing until you:

Guess the correct number, or

Run out of attempts.
